# orbiqueglobal.com

The Orbique Global group website. One static page (`index.html`) plus two wordmark images, no build step.

- Hosted on Vercel, project `orbique-global`, Root Directory `orbiqueglobal/`; every push to `main` goes live.
- Source of the page lives in the Orbique Claude project (`orbique-site/corporate/`: `copy-final.json` + `template.html`, built with `build.py`). Copy the built `index.html` here to update.
