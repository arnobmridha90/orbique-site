
Orbique Global - Modern Gradient React + Tailwind starter
--------------------------------------------------------

What's included:
- Vite + React starter (minimal)
- TailwindCSS config
- Modern gradient hero
- Animated CSS-only client logo carousel (logos placed in src/assets/clients/)
- Logo placed in src/assets/logo.png (from uploaded image)

How to run locally:
1. npm install
2. npm run dev
3. Open http://localhost:5173

How to build for production:
1. npm run build
2. The build output will be in 'dist'. Zip the contents and upload to your Namecheap public_html.

Notes:
- Client logos have been integrated and optimized.
- If you'd like, I can guide you through uploading the built files to Namecheap cPanel.
